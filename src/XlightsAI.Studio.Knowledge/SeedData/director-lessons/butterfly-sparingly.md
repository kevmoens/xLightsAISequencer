Use Butterfly sparingly. It is a valid effect, not a forbidden one, but it reads as a strong, busy, high-duty-cycle signature move -- reserve it for a genuine rare moment (a specific peak/pop), not a default go-to for a hold layer or a Tree/Matrixes accent layer. When in doubt, prefer Twinkle, Sparkles, Snowflakes, or Color Wash instead.
