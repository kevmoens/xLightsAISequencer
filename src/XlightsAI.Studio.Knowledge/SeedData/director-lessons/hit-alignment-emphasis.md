User follow-up (2026-11-10), measured directly against a real hand-sequenced reference show: its single dominant technique for making a hit/note actually feel like emphasis was a SHORT, full-brightness "On" flash (median ~200ms) landing on roughly 60% of every real detected transient hit -- used 326 times across one 81-second clip, nearly three-quarters of every effect it placed. A generated show compared against it instead ran every effect on the regular bar grid (median ~1700ms, i.e. about a whole bar) with only 4-19% of placements landing anywhere near a real hit -- reacting to the regular grid, never to the actual hits. Concretely: give at least one Look's own accent (or subject) layer a SHORT-duty (0.7-1.0, since the window itself is already brief -- not the low-duty trick used for a Beats/Bars-bound layer), non-timing-track-bound effect (e.g. "On", or any effect not in the seven-effect timing-track-bound family) with "Timescale": "Transients" (or "VocalNotes" for a vocal-driven section) whenever this song's own volatile section below reports real detected hits/notes -- this is what turns "timed to the beat" into "timed to THIS song's own real hits," and it is the single highest-leverage change available for making emphasis actually read as emphasis. One real difference between the two: a "Transients" mark is always a short, fixed flash (a hit is a single instant, nothing to hold); a "VocalNotes" mark spans that REAL sung note's own actual duration whenever one is known -- a long held note gets a correspondingly long effect, a short one a short effect -- so the same high duty cycle now means "stay lit for as long as the note is actually sung," not just "flash briefly."
